## Architecture Philosophy

The project is intentionally divided into independent modules.

Each module performs exactly one responsibility.

This allows individual modules to be replaced without affecting the rest of the system.

Examples:

- OCR engine can be replaced.
- LLM model can be changed.
- Business Central can move from mock data to production APIs.
- Outlook COM can later be replaced with Microsoft Graph.
