# Development History

## Phase 1

Initially attempted Microsoft Graph API.

Issue:

Company tenant enforced Token Protection policies.

Result:

Device Code Flow could not access Outlook.

Decision:

Switch to Outlook COM.

Reason:

Runs locally under the logged-in Windows user and avoids authentication restrictions.

---

## Phase 2

Built Outlook COM integration.

Capabilities:

- Read unread emails
- Mark emails as read
- Save attachments

---

## Phase 3
